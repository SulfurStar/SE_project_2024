🏠 學生校外住宿管理系統
前端技術：Vue / Nuxt3 後端技術：Flask 資料庫：PostgreSQL

📖 專案簡介
本系統旨在為學生提供一個便利的校外住宿平台，讓學生能夠輕鬆搜尋房源、討論租屋問題並尋找室友；同時，房東可以刊登房源資訊，校方則能夠記錄學生租房狀況並與學生互動。

🎯 主要功能
學生：搜尋可租房源 發布租屋討論 徵求室友

房東：刊登房源 管理租屋資訊

校方：監督學生租房狀況 與學生進行租屋相關互動

🏗 架構概述
前端（Vue / Nuxt3）
- 負責提供使用者介面與互動體驗。

- 使用 Nuxt3 建立頁面，如房源列表、登入介面等。

- 透過 Fetch API 發送 HTTP 請求（API）給後端。

後端（Flask）
- 接收前端請求，例如 /api/login 或 /api/houses。

- 根據不同的 API 路徑與身分（學生、房東、管理員），進行：資料查詢 身分驗證 資料儲存

資料庫（PostgreSQL）

- Flask 使用 SQLAlchemy 操作 PostgreSQL 以進行：學生租屋申請紀錄 新增房源資訊 驗證登入帳號密碼（雜湊比對）

回應前端

- Flask 會將處理結果轉為 JSON 並回傳：成功登入則儲存 JWT token 查詢結果則顯示於 UI
